# EPL Prediction Engine

A reproducible English Premier League prediction and backtesting engine built around match-level xG, Poisson probabilities, calibration, and bookmaker comparison.

## Current scope

- Automated EPL data pipeline
- Match-level xG/xGA ingestion
- Poisson total-goals probabilities
- Walk-forward calibration
- Brier score and log-loss evaluation
- Historical EV and ROI backtesting

## Project goal

Build a maintainable football prediction engine where every model change is tested out of sample before it is accepted.
